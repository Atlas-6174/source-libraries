Privacy Notice

Last updated October 2026

This site is a self-hosted build of open-source UI libraries. It has no accounts, no payments, no analytics and no cookies. This notice explains the little data that still moves when you use it, and who is responsible for it.

Who runs this site

This instance is operated by whoever deployed it (the "operator"). It is built from the Source Libraries project, an independent fork of the MIT-licensed libraries published by Jakub Antalik at Libraries.dev. Neither the fork's maintainers nor Libraries.dev operate this instance or receive data from it.

Operators: name yourself and a contact address here before making the site available to others, and adjust the sections below to match your setup (for example, a reverse proxy or log retention).

What this site collects

Nothing you type on this site is submitted anywhere. There are no sign-in forms or newsletters, and feedback goes to GitHub Issues (see below).

Server logs. Like any web server, the nginx server behind this site records each request: IP address, date and time, requested URL, response status and browser user agent. Logs go to the container's standard output; how long they are kept depends on the operator's configuration.

What stays in your browser

The site stores a few values in your browser, under keys that start with ldev:. None of them contains personal data, and none is sent anywhere:

  • Local storage (kept until you clear it): Studio presets you save (ldev:studio:presets:*), the Studio theme and stage fill, and ldev:auth, a flag that makes the pages show the open Studio.
  • Session storage (cleared when you close the tab): cached GitHub star and npm download counts.

There are no cookies. Clear this site's data in your browser to remove everything.

Microphone. The Voice demos ask for microphone access only when you start them. The audio is analysed locally to drive the animation and is never recorded or uploaded.

Third parties your browser contacts

Loading these pages makes your browser request resources directly from:

  • Google Fonts (fonts.googleapis.com, fonts.gstatic.com), for the typefaces. Google receives your IP address and user agent.
  • npm (api.npmjs.org) and GitHub (api.github.com), for public download and star counts.

Links to GitHub, X or npm take you to those services, whose own privacy policies apply. Feedback and support are handled through GitHub Issues; anything you post there is public and governed by GitHub.

Your rights

Depending on where you live (for example under the GDPR or Mexico's LFPDPPP), you may have rights to access, correct or delete personal data, such as entries in the server logs. Contact the operator of this instance to exercise them.

Changes to this notice

Changes are published on this page with a new date above.
