Studio Free

Every library, tuned to yours

The Studio is one workbench for all five libraries. Tune every parameter live, far beyond the public playgrounds, save presets in your browser, and export the exact code.

Open Studio

Features

  • Extra variants and types

    Every state, size and effect type the public playgrounds hold back.

  • The full parameter surface

    Every knob the libraries expose, tuned live and exported as props.

  • AI agent (hosted only)

    The hosted Libraries.dev Studio adds an agent that moves the knobs for you. This self-hosted build ships every manual control.
